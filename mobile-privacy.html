Mobile Privacy Policy

Effective: August 28, 2026

KuiqKolor Mobile is designed to function without an account, advertising, analytics, tracking, or an online account service.

Developer

nakOza
nakOza@live.com

Data Collection

The current version of KuiqKolor Mobile does not collect or transmit personal or sensitive user data to the developer.

The app does not include an account system, advertising SDK, analytics SDK, behavioral tracking, remote profile, or cloud-sync service.

Local App Data

Saved colors, saved palettes, lock state, preset preferences, and related app settings are stored locally on the device. This local data is not uploaded to a developer-operated server.

Clipboard

When a user chooses to copy a HEX color value, KuiqKolor writes that selected value to the operating system clipboard. KuiqKolor does not transmit clipboard contents to the developer.

Palette Sharing

When a user chooses Share, KuiqKolor generates a temporary palette image and passes it to the operating system's native share interface. KuiqKolor does not upload that image to a developer-operated server. Any destination selected by the user is governed by that service's own privacy practices.

Data Retention

Locally saved colors, palettes, and preferences remain on the device until removed in the app, cleared through device storage controls, or removed when the app is uninstalled. Temporary share images are stored in operating-system temporary storage and may be removed by the operating system.

Children

KuiqKolor is a general-purpose color and design utility and is not specifically directed to children.

Changes

If KuiqKolor's features or data practices change, this policy will be updated to reflect those changes.
