# KuiqKolor Privacy Page

This folder is a standalone static privacy-policy website for KuiqKolor v1.11.1.

## Files
- `index.html` — the privacy page
- `assets/kuiqkolor-icon.png` — final KuiqKolor icon

## GitHub Pages
1. Create a new public GitHub repository, for example `kuiqkolor-privacy`.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open the repository **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide a public HTTPS address.
9. Use that public page as the Privacy Policy URL in the Chrome Web Store dashboard.

No build system, JavaScript, external fonts, analytics, or external assets are required.
