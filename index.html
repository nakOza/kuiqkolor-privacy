KuiqKolor
Chrome Extension

Privacy Policy

Effective date: August 18, 2026

KuiqKolor is a compact color and preset randomizer for Chrome. It is designed to work locally in your browser, does not require an account, and does not send your saved colors, palettes, or browsing activity to the developer.

No tracking No analytics No advertising User-initiated active-tab access Local storage only

1. Overview

This Privacy Policy explains what information KuiqKolor stores, how that information is used, and how the extension handles user data.

2. Data stored by KuiqKolor

KuiqKolor uses Chrome's extension storage to remember information needed for its features. This may include:

  • The current five-color palette.
  • Color lock states.
  • Individually saved colors.
  • Saved five-color palettes, including palettes generated from presets.
  • The selected preset category.
  • Local preset-randomizer state used to avoid immediate preset repetition.
  • Basic interface state required to preserve your choices between panel sessions.
  • The floating panel's last expanded size and position.
This information is stored using chrome.storage.local inside the extension's local Chrome storage.

3. How stored data is used

KuiqKolor uses locally stored information only to provide its color generation, preset randomization, locking, favorite, and saved-palette features and to preserve your choices between uses of the extension.

4. Data collection and transmission

KuiqKolor does not operate a developer-controlled server for user data. The extension does not transmit your saved colors, saved palettes, browsing activity, or extension state to the developer or to third parties.

KuiqKolor does not use analytics SDKs, telemetry services, advertising networks, tracking pixels, or behavioral profiling.

5. Data sharing and sale

KuiqKolor does not sell, rent, share, or transfer extension user data to advertisers, data brokers, analytics providers, or other third parties.

6. Website and browsing access

KuiqKolor does not request persistent host permissions. When you explicitly click the KuiqKolor toolbar icon, Chrome's activeTab permission provides temporary access to that active webpage so KuiqKolor can insert, display, resize, move, minimize, restore, or remove its floating interface.

KuiqKolor does not use this temporary access to read, collect, transmit, or monitor webpage content, browsing history, cookies, form data, communications, or other website data. Access is user-initiated and is limited by Chrome's activeTab permission model.

7. Chrome permissions

KuiqKolor requests storage, activeTab, and scripting. storage preserves the local app state, saved colors, saved palettes, preset state, and floating-panel layout. activeTab provides temporary access only after you invoke KuiqKolor on the current webpage. scripting is used only to inject or toggle KuiqKolor's packaged floating-panel code on that active page.

KuiqKolor does not request persistent <all_urls> host permission and does not execute remotely hosted code.

8. Data retention and deletion

Locally saved data remains in Chrome's extension storage until it is changed or removed through KuiqKolor, cleared through browser/extension controls, or removed as part of Chrome's extension-data lifecycle.

Individual saved colors and palettes can be removed directly from KuiqKolor's Saved interface.

9. Security

Because KuiqKolor's saved extension data is not transmitted to a developer-controlled server, there is no remote user-data database operated by KuiqKolor. Data stored by the extension is subject to Chrome and the user's device/browser security controls.

10. Chrome Web Store Limited Use

KuiqKolor's use of information is limited to providing and maintaining the extension's single purpose: generating, exploring, copying, locking, and locally saving colors and palettes. KuiqKolor does not use extension data for advertising, profiling, unrelated market research, or other unrelated purposes.

11. Changes to this policy

If KuiqKolor's data practices change in a future version, this policy will be updated to accurately describe the new practices and the effective date will be revised.

12. Contact

For privacy questions about KuiqKolor, contact the developer using the support contact provided on KuiqKolor's Chrome Web Store listing.
